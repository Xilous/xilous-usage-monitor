# Glossary

- THEME - the widget's colours: a preset (or System, which follows Windows between Graphite and Paper) or the user's own Custom theme, as nine colour roles, plus how windows and warnings are coloured and what the widget stands on. code: `Appearance.theme`, `Roles`, `PRESETS`, `Palette`
- PACE BAR - an expanded row's straight bar: usage fill, a notch where an even spend would be, and hatching past the notch when ahead of it; each collapsed ring unrolls into one. code: `Tape`, `dock::Card`
- WIDGET SIZE - the user-chosen scale of the floating widget, as a percentage of its default size (75% to 200% in 5% steps), applied on top of monitor DPI scaling and set with the Widget size slider in the appearance studio. code: `Appearance.widget_size`, `WIDGET_SIZE`, `widget_sc`
